OBJECTIVE

Create accurate, comprehensive, self-contained English study materials that I can use as my primary study resource without reopening the original files.

Prioritize complete knowledge coverage, mathematical accuracy, clear explanations, and useful learning representations over brevity. Keep exercise solutions concise once the general method has been taught.

If notes already exist, audit and improve them. Preserve correct content, correct errors, and fill gaps.

The final deliverables must use the exact two-file LaTeX structure defined in Section 13. Do not split content into additional LaTeX files.

1. USE TWO SUBAGENTS

Use two subagents with separate reading responsibilities:

- Subagent 1: Review every page of all weekly lecture slides, handwritten notes, worksheets, annotations, diagrams, examples, and unanswered questions.
- Subagent 2: Review only the specified textbook section and the assigned or suggested textbook exercises. Stay within the stated textbook boundaries.

Combine their findings into one coherent set of notes. Independently verify the final content against the sources.

2. REVIEW EVERY SOURCE PAGE

Check every page of every weekly file, including:

- Printed content
- Handwritten annotations
- Tables, graphs, and diagrams
- Worked examples
- Unanswered worksheet questions
- Instructor comments
- Review, supplementary, preview, and next-week material

Visually inspect PDF pages so that diagrams, handwriting, and spatial information are not missed by text extraction.

Do not guess when content is unreadable or ambiguous. Record unresolved items in the coverage appendix of the answer file.

3. ORGANIZE BY KNOWLEDGE POINT

Organize the notes by mathematical concept rather than source-file order.

Clearly label content as:

- Core material
- Supplementary material
- Preview material

Include every distinct topic appearing in the weekly files, even when a source identifies it as review or later-week material. Label its status instead of silently omitting it.

Explain each concept fully in its main section. Do not repeat the same detailed tutorial under every exercise.

Give special emphasis to the sections or topics named in the inputs. This should affect explanation depth, number of representations, and practice coverage, but must not cause other weekly material to be omitted.

4. EXACT DIVISION BETWEEN THE TWO TEX FILES

File 1: `Study-Notes.tex`

This is the main learning file. It must contain:

- The complete conceptual notes
- Definitions, notation, intuition, conditions, recognition cues, and general methods
- Core, supplementary, and preview labels
- All Problem type sections
- The complete question for every Problem type teaching example
- All tables, graphs, diagrams, and data required to attempt those Problem type questions
- Answer checklists and common mistakes that do not reveal the specific teaching-example answer
- Internal labels that the second file can reference by visible section title or matching Problem Type ID

File 1 must not contain:

- Worked solutions to the Problem type teaching examples
- Final answers to the Problem type teaching examples
- Assigned textbook exercise solutions
- Weekly worksheet solutions
- Self-test solutions

File 2: `Answers-and-Practice.tex`

This is the solutions and practice file. It must contain, in this order:

1. Complete worked solutions and final answers for every Problem type teaching example from `Study-Notes.tex`
2. Every actual weekly lecture, worksheet, or handwritten question, with source label, complete wording, necessary source data, concise necessary work, and final answer
3. Every assigned or suggested textbook exercise, with complete wording, all subparts, required source data or figures, concise necessary work, and final answer
4. A separate original self-test covering all major weekly topics
5. The self-test answers and concise correction explanations
6. A compact source-coverage and unresolved-items appendix

Do not create separate files such as `Weekly-Questions.tex`, `Textbook-Practice.tex`, `Self-Test.tex`, `Coverage-Audit.tex`, or any other content `.tex` file. All of that material belongs inside one of the two required files.

5. COMPLETE KNOWLEDGE EXPLANATIONS

For each concept and problem type in `Study-Notes.tex`, explain:

- Meaning and intuition
- Relevant notation and variables
- Conditions under which it applies
- How to recognize the problem type
- The general method
- What a mathematically complete answer contains
- Common mistakes
- Units and interpretation when relevant

Detailed instruction belongs in the knowledge-point and Problem type sections of `Study-Notes.tex`.

6. PROBLEM TYPE FORMAT AND CROSS-FILE MATCHING

Assign every Problem type a stable ID such as `PT-01`, `PT-02`, and so on. Use the same ID and title in both files.

In `Study-Notes.tex`, use this structure:

\subsection{Problem Type PT-XX: [Name]}

\textbf{Meaning and recognition.}

[Explain the concept, notation, conditions, and how to recognize the problem type.]

\textbf{General method.}

[Give a clear reusable method.]

\textbf{Teaching example.}

\textbf{Question.}

[State a complete original question, including all variables, units, conditions, and subparts.]

[Display every required labelled table, graph, or diagram.]

\textbf{A complete answer must include.}

[Give a short checklist without revealing the numerical or final answer.]

\textbf{Common mistakes.}

[Explain relevant mistakes concisely.]

In `Answers-and-Practice.tex`, use this matching structure:

\subsection{Problem Type PT-XX: [Same Name]}

\textbf{Question reference.} See Problem Type PT-XX in `Study-Notes.tex`.

\textbf{Worked solution.}

[Explain the reasoning and calculations that teach the method.]

\textbf{Answer.}

[Give the complete final answer, with units and interpretation when relevant.]

Every Problem type in File 1 must have exactly one matching solution section in File 2. Do not leave any unmatched IDs.

Distinguish question sources accurately:

- Label original instructional questions as “Teaching example.”
- Label actual textbook questions with their section and exercise or example number.
- Label actual worksheet or lecture questions with source filename, page, and question number when available.
- Do not present an original question as a textbook, lecture, or worksheet question.
- Preserve the complete wording and every subpart of actual source questions.

7. INCLUDE ACTUAL LEARNING REPRESENTATIONS

Every topic must include the representation needed to learn it. Merely mentioning or verbally describing a required table, graph, or diagram is insufficient.

For numerical tables:

- Reproduce the complete labelled table required for the topic or question.
- Define the row variable, column variable, and entries.
- Include units.
- Show at least one exact lookup in the relevant solution.
- Explain reading across a row and down a column.
- State which variable is held fixed.
- Explain relevant trends, estimation, or interpolation.

For graphs and diagrams:

- Create or extract accurate labelled figures.
- Label axes, variables, units, important points, curves, and surfaces.
- Explain how to read each figure.
- Identify relevant intercepts, traces, and cross-sections.
- Describe orientation, symmetry, and extent.
- State which variables are fixed and which are free.
- Identify whether the object is a curve, plane, surface, cylinder, sphere, ball, or region.

If an infinite object is drawn as a finite patch, explicitly state that the patch is only a viewing window.

For contour maps:

- Display the actual map required by the example or question.
- Show contour labels and relevant locations.
- Explain how to identify surrounding contours.
- Give a justified range before a numerical estimate.
- Explain interpolation assumptions.
- Explain what close and wide contour spacing indicate when contour-value intervals are comparable.

[Complete wording, including every part.]

[Required source table, graph, or diagram.]

\textbf{Necessary work.}

[Only what is needed to justify the answer.]

\textbf{Answer.}

[Complete final answer with units and interpretation when required.]

For multiple parts, label the necessary work and answer for each part separately.

Do not repeat the full general tutorial under every exercise. Put reusable teaching in `Study-Notes.tex`.

- Avoid unsupported fonts or machine-specific absolute image paths.
- Escape LaTeX special characters correctly.
- Give every important section and Problem Type a stable label when useful.
